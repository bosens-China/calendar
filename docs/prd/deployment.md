# 个人版与团队版

## GitHub Pages 个人版

- 操作者访问工作台即可管理团队。人员记录用于排期，工作台无需登录。首次打开会添加自己的排期身份和一个默认项目。
- 排期、请假、人员、项目、系统配置与显示偏好保存在当前浏览器访问该站点时使用的 IndexedDB。不同浏览器与设备各自维护一份数据。
- 节假日从内置规则开始。管理员可在工作台主动导入 GitHub 的公开节假日数据，结果保存到本机。

## Docker Hub 团队版

- 单个容器提供同源的前端和 API。管理员分配账号和权限角色，通过一次性邀请让成员自行设置密码。成员登录后可以管理自己的任务和请假。
- 首次初始化由部署者提供管理员密码。数据库与默认会话签名密钥保存在持久卷中。服务启动时使用 Drizzle 应用迁移，保留现有数据。
- 服务按年同步节假日，跨年保留历史设置。管理员的手动规则会保留，主动同步或重置时由管理员确认替换范围。
- 部署、仓库变量和验收命令见 [README](../../README.md)。接口请求契约见运行中的 `/api/docs`。

两个版本共用排期、工作时段、统计规则和界面。个人版和团队版各自存储，旧版浏览器数据迁移不在当前范围。

个人版和团队版都在当前浏览器记住主题、周/月模式和「隐藏周末与节假日」偏好。重置个人界面偏好或恢复初始化时，恢复默认显示。
