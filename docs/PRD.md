# 团队日程与任务排期管理工具 — 重构 PRD（v1.0）

## 1. 产品定位与核心目标

面向团队管理者与组员的**多项目任务排期与日历管理工具**。

- **核心价值 1（无缝排期）**：直观发现每个成员在每个工作日是否存在**空档或工作未满**，快速拖拽/填补排期，实现任务无缝衔接。
- **核心价值 2（工作回顾）**：按**周 / 月**维度，直观查看每个成员（包含管理员本人）在不同项目下做了什么、工时饱和度与完成情况。
- **核心价值 3（轻量协同）**：管理员统筹全局排期，成员登录后查看自己的任务记录、填写自己的请假并对任务进行轻量微调。

### 使用方式

支持 GitHub Pages 个人版和 Docker Hub 团队部署。两者的登录、权限和存储边界见 [个人版与团队版](./prd/deployment.md)。排期日期、今日与默认节假日年份统一按北京时间确定。

## 2. 用户角色与权限矩阵

团队版包含 **管理员 (Admin)** 与 **成员 (Member)** 两种角色。个人版的操作者使用管理员能力，其他成员只作为排期对象。

| 功能模块 | 管理员 (`admin`) | 成员 (`member`) |
| :--- | :---: | :---: |
| 账号密码登录 / 修改密码 | ✅ | ✅ |
| 人员管理（邀请、增删改、启停、重置密码） | ✅ | ❌ |
| 项目管理（新建、编辑、归档、配色） | ✅ | 仅查看项目信息 |
| 节假日 / 调休 / 工作时段配置 | ✅ | 仅查看 |
| 请假登记与管理 | ✅（全员） | ✅（仅自己） |
| 任务查看 | ✅（全员、全项目） | ✅（**仅查看自己的任务**） |
| 任务新建 / 指派 / 删除 | ✅ | ❌ |
| 任务微调（状态、备注、起止时间微调） | ✅（全员） | ✅（仅分配给自己的任务） |
| 周 / 月统计复盘 | ✅（全员 & 按项目） | ✅（仅个人） |

> 管理员本人同样作为一名团队成员存在，可被分配任务、登记请假并纳入排期与统计。

## 3. 核心业务规则

### 3.1 自定义工作时段（跳过非工作时间）
- 全局支持配置每日工作时段，默认配置：
  - **上午**：`09:00 - 12:00`（3.0h）
  - **下午**：`13:30 - 18:00`（4.5h）
  - 每日标准工时合计 = `7.5h`（支持管理员在系统设置中自定义多个工作时段及起止时间）。
- **任务排期与渲染规则**：
  - 任务以 `开始日期 + 开始时间` 至 `结束日期 + 结束时间` 表示（交互上支持一键快捷选「上午 / 下午 / 全天」，也支持按半小时粒度微调）。
  - 午休、下班夜间、周末和法定节假日不计入有效工时。时间轴默认显示周末与节假日，成员行中的对应日期格用灰底标记。
  - 跨天任务自动将任务段连续切分到每个应出勤工作日的有效工作时段中展示。

### 3.2 法定节假日与调休
- **数据源与跨年自动拉取**：两种部署均内置 2026–2027 节假日兜底数据。团队版按年自动拉取 GitHub 数据并保存到 SQLite，个人版由操作者主动同步并保存到 IndexedDB。
- **跨年留存与更新**：各年份分别保存。查看新年份时，团队版会检查更新，管理员也可在「系统设置」手动同步指定年份。
- **日期范围限制**：系统统一限定最小可选日期为 **2026-01-01**（禁止选择 2026 年之前的日期与年份）。
- 管理员可在「系统设置」中按年查看并手动新增/修改/删除任意日期的节假日或调休补班标记。
- 日历视图清晰标注节日名称、「休」标（灰显免排期）与「班」标（视为正常工作日）。

### 3.3 个人请假
- **管理员**可为任意成员标记请假，**成员本人**也可登记、编辑或取消自己的请假。
- 请假支持精确到**时段**（上午 / 下午 / 全天 / 自定义时间段），类型包含：`年假`、`病假`、`事假`、`调休`、`其他`。
- 请假时段在日历中以独立视觉样式（斜纹柔和色块 + 请假标签）展示，**从应出勤工时中扣除，不触发空档提示**。

### 3.4 “工作未满 / 空档”缺省提示规则
对每个成员在每个应出勤工作日：
- `应出勤时长` = 当日标准工作时段总时长 − 当日有效请假时长（落在工作时段内）。
- `已排任务时长` = 当日所有非取消任务落在工作时段内（且剔除请假重叠）的**并集覆盖时长**。
- **状态判定**：
  - **完全空档（0%）**：`应出勤时长 > 0` 且 `已排任务时长 == 0` → 强提示（虚线占位块 + 空档角标）。
  - **工作未满（0% < 饱和度 < 100%）**：存在未覆盖的工作子时段 → 缺省提示（在空闲子时段显示浅橙色提示条，如「空余 3h / 下午空闲」）。
  - **已排满（100%）**：当日工作时段无缝覆盖，绿色状态，无告警。
  - **并行冲突**：同一成员在同一工作子时段有 ≥2 个重叠任务 → 显示轻量并行角标，不阻断排期。

## 4. 功能模块详细设计

### 4.1 团队版登录与忘记密码
- 基础 **用户名 + 密码** 登录，JWT Bearer Token 鉴权（自动生成持久化随机密钥，改密/重置后旧 Token 立即失效）。
- 登录页支持 **忘记密码**：输入登录账号与绑定邮箱校验匹配后，可直接设置新密码。
- 管理员可在「人员管理」中邀请成员、设置绑定邮箱或重置已开通账号的密码。

### 4.2 工作台（核心横向排期图表）
导航精简为 4 个核心入口：**工作台**、**项目管理**、**人员管理（仅管理员）**、**系统设置**。
- 工作台使用横向时间轴，默认按周展示，也可切换到月视图。月视图日期列等宽，横向滚动条从日期区左边缘开始，也可以拖动画布或使用触控板横向滚动。左侧成员区高度随可用画布高度确定，成员较多时与排期行一起纵向滚动，管理员添加人员的入口固定在底部。
  - 周末和法定节假日的灰底随可见成员行增减。月视图的未来工作日也使用灰底标记。周视图用浅红提示全天空档，用浅黄提示部分空档。月视图可通过「检查空闲」强调未来工作日的空档。任务用成员颜色标识并附项目标签，请假独立显示。
  - 顶部提供周/月切换、周期翻页（最早 2026-01-01）、项目多选、成员多选（管理员）、「检查空闲」、「周/月复盘」和新建入口。成员多选按选中人员显示，项目多选筛选任务显示。「检查空闲」筛出选中人员中在当前周期从今天起仍有空档的人，空档按实际排期计算。
  - **周/月复盘改为弹窗**：点击工作台「周/月复盘」直接弹出当前周期的成员/项目复盘汇总，并支持一键复制 Markdown。

### 4.3 任务分配与微调
- 任务字段：
  - `title`：任务标题（必填）
  - `projectId`：所属项目（必填，继承项目颜色）
  - `assigneeId`：负责人（成员 ID）
  - `startDate` / `startTime`：开始日期与时间（如 `2026-11-25` + `09:00`）
  - `endDate` / `endTime`：结束日期与时间（如 `2026-11-27` + `18:00`）
  - `status`：`todo`（待开始）| `in_progress`（进行中）| `done`（已完成）| `delayed`（已延期）
  - `priority`：`high` | `medium` | `low`
  - `description`：备注/进展说明
  - `adjustedByMember`：布尔标记（成员微调后自动标示，便于管理员感知）
- 快捷时间选择：提供「上午」「下午」「全天」一键预设按钮，也支持自由选时间点。

### 4.4 人员管理（仅管理员）
- 成员列表：姓名、用户名（登录账号）、角色（管理员/成员）、职位/标签、头像颜色、状态（在职/停用）。
- 管理员指定登录账号、姓名和权限角色，生成邀请链接。成员打开邀请后设置密码即可加入。链接 48 小时内有效，仅可使用一次，管理员可以撤销或重新生成。
- 成员请假管理入口（也可在独立「请假管理」或日历上快捷登记）。

### 4.5 项目管理
- 管理员可新建、编辑、归档项目（名称、标识色、描述、状态）。
- 默认内置一个「默认项目」便于开箱即用。

### 4.6 周 / 月复盘统计
- 选择任意「周」或「月」，自动按**人员维度**和**项目维度**生成复盘报告：
  - 应出勤工时、已排工时、空闲工时、饱和度百分比
  - 任务完成统计（总数 / 已完成 / 进行中 / 待开始 / 延期）
  - 按项目工时分布与具体任务清单
- 支持一键复制为 **Markdown 周报 / 月报**。

### 4.7 系统设置
- **个人资料**：团队成员和个人版操作者都可以修改自己的姓名。
- **角色显示名称**：团队管理员可修改两种角色的显示名称。成员的权限继续由分配的角色决定。
- 「日历显示」可保存当前浏览器的「隐藏周末与节假日」偏好，默认关闭，调休补班日仍按工作日显示。
- **工作时段配置**：管理员增删改每日工作时段（默认上午 `09:00-12:00`、下午 `13:30-18:00`），保存后全局生效。
- **法定节假日与调休配置**：按年份查看、导入内置法定节假日、手动增删改单日「休 / 班」属性。

## 5. 技术架构设计

基于现有 pnpm Monorepo 重构为三个子包：

```text
calendar/
├── docs/
│   └── PRD.md                 # 产品需求文档
├── packages/
│   ├── shared/                # 共享类型、工作时段/空档计算引擎、节假日内置数据
│   ├── server/                # 后端服务：Hono + @hono/node-server + Node SQLite + Drizzle + Zod
│   └── app/                   # 前端应用：Vite + React 19 + TypeScript + Tailwind CSS + Radix UI + TanStack Query + Zustand
└── package.json               # 根目录并发启动、构建与校验脚本
```

Docker 团队版通过 `/api/docs` 提供接口文档。两种数据接入共享排期计算、校验与数据类型。

## 6. 验收标准
1. 团队版的管理员和成员都能登录。成员只能查看和微调自己的任务、查看个人统计和登记自己的请假。个人版直接进入工作台，刷新后可读取已有本机数据。
2. 时间轴支持周/月切换。月视图列等宽、可横向滚动，未来日期显示灰底。成员区可纵向滚动，添加人员入口固定在底部。
3. 支持自定义工作时段，非工作时间自动跳过工时计算，周末与节假日默认灰显并可在设置中隐藏。请假免除对应时段的空档提示。
4. 支持成员及项目多选、「检查空闲」和周/月复盘，复盘可一键复制 Markdown。
5. 前后端构建（`typecheck` / `build`）与核心单测/接口联调全部通过。
